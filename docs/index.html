用 Python 畫出「像論文一樣」的地圖與剖面：PyGMT

PyGMT 是 GMT（Generic Mapping Tools） 的 Python 介面。簡單說：你用 Python 寫幾行，就能產出 版面乾淨、線條銳利、標註一致、可重現（reproducible）的地球科學圖。

地圖 / 地形 / 海深 震源分布 / 斷層 / 板塊邊界 剖面 / 走向剖面 論文等級排版
一句話定位 「用 Python 控制 GMT：把地科繪圖變成程式化流水線。」
很適合你用在 板塊邊界、地震/火山、DEM、海洋地形、氣象/海氣資料可視化。
為什麼看起來很專業 預設字體、刻度、投影、色階都偏向「出版級」習慣。

PyGMT 是什麼？

概念 1 分鐘懂

GMT 是地球科學界很常用的繪圖工具（地圖、投影、地形、刻度、標註都很強）， PyGMT 則是讓你用 Python 去呼叫 GMT 的功能。

  • 程式化繪圖：把繪圖流程寫成程式，就能「可重現」。
  • 出版級美感：刻度、字體、線條、投影的細節控制很到位。
  • 與科學資料搭配：常和 xarray / numpy / pandas 搭配做資料處理，再用 PyGMT 出圖。
✅ 如果你需要「每週更新一張圖」或「換資料就重出同風格圖」，PyGMT 會非常香。

為什麼不用純 matplotlib？

不是取代，是分工

matplotlib 很萬用，但在「地圖投影、地形渲染、刻度樣式一致性」這類地科細節上，GMT 的底子很強。

  • 投影與刻度：GMT 的投影與地圖框架是強項。
  • 地形/海深：現成色階、陰影（shading）處理很成熟。
  • 排版：多張子圖、圖例、比例尺、指北針都好控。
小策略：資料分析用 pandas/xarray，高品質地圖用 PyGMT。

安裝與環境建議

避免踩雷版

最推薦用 conda-forge 安裝（因為 GMT 本身包含不少系統相依套件）。如果你用 pip，常見狀況是 「Python 裝好了，但 GMT 或系統 library 沒裝好」。 

conda create -n pygmt -c conda-forge python=3.11 pygmt
conda activate pygmt
conda install -n base -c conda-forge mamba
mamba create -n pygmt -c conda-forge python=3.11 pygmt
mamba activate pygmt
# pip 版通常需要你先能在系統上用到 GMT
# 例如：macOS 用 brew，Linux 用套件管理器，Windows 需確認 GMT 安裝與環境變數
pip install pygmt
python -c "import pygmt; print('PyGMT OK ✅', pygmt.__version__)"
gmt --version
✅ 想要最少麻煩：Conda / Mamba 一次裝好 PyGMT + GMT。
🧯 若你是在 Jupyter/Colab 類環境：要注意系統層的 GMT 是否真的可用。

範例食譜 A：畫一張地形底圖 + 海岸線

最經典的開場

這份範例做的事：設定範圍與投影 → 疊地形（含陰影）→ 疊海岸線 → 加色階。 

import pygmt

region = [119, 123, 21.5, 25.5]  # 台灣附近範圍（示意）
fig = pygmt.Figure()

# 地形網格（示意：使用 GMT 內建資料時需可用的環境）
grid = pygmt.datasets.load_earth_relief(resolution="15s", region=region)
shade = pygmt.grdgradient(grid=grid, azimuth=315, normalization="t1")

fig.grdimage(
    grid=grid,
    region=region,
    projection="M15c",
    shading=shade,
    cmap="geo",
    frame=["af", "+tPyGMT 地形底圖示例"]
)

fig.coast(shorelines="1/0.5p,white", borders="1/0.5p,white", water="navy@15")
fig.colorbar(frame='af+l"Elevation (m)"')

fig.show()
小技巧：grdgradient 做陰影後，地形立體感會直接升級。

範例食譜 B：疊加地震點（大小=規模）

研究圖常用套路

你可以用 pandas 讀表，再把經緯度與規模映射到點的大小/顏色。下面用「假資料」示意。 

import pandas as pd
import pygmt

# 假資料：lon, lat, mag
df = pd.DataFrame({
    "lon": [121.5, 121.0, 120.8, 122.0],
    "lat": [24.0, 23.6, 22.9, 24.8],
    "mag": [4.2, 5.1, 4.6, 6.0]
})

region = [119, 123, 21.5, 25.5]
fig = pygmt.Figure()
fig.basemap(region=region, projection="M15c", frame=["af", "+t地震點疊圖（示意）"])
fig.coast(land="gray20", water="gray10", shorelines="1/0.4p,white")

# 點大小跟 mag 有關（示意比例）
sizes = 0.08 + 0.08 * (df["mag"] - df["mag"].min())

fig.plot(
    x=df["lon"],
    y=df["lat"],
    style="c",     # circle
    size=sizes,
    fill="tomato",
    pen="0.3p,white",
    transparency=15
)

fig.show()
想做得更像論文：加上圖例（legend）、規模分級（bins）、或用顏色代表深度。

範例食譜 C：板塊邊界與地形景觀（概念版）

把「地科故事」畫出來

板塊邊界常見三大類：聚合（隱沒/碰撞）、張裂（離散）、轉形（走滑）。它們對應的典型地形景觀也很有辨識度：

  • 聚合邊界：海溝、島弧火山、造山帶、增積楔（例如日本海溝—日本島弧）。
  • 張裂邊界：洋中脊、裂谷、玄武岩質噴發與新生海洋地殼（例如大西洋中洋脊）。
  • 轉形邊界：線性谷地、斷層地形、地震頻繁但火山不一定常見（例如聖安德烈斯斷層）。
🎯 小挑戰：下次看到一張海深/地形圖，先找「海溝」或「洋中脊」的形狀，你會很快開始「用地形猜板塊」。
若你要把「板塊邊界線資料」疊上去：請先確定 GeoJSON / Shapefile 的幾何與欄位正常（例如 LineString、座標順序、是否含空幾何），避免出現欄位數不符的 warning。

繪圖小技巧（讓圖瞬間高級）

實用清單
  • 陰影（shading）：地形一定要試 grdgradient，立體感差很多。
  • 色階（cmap）：地形用 geo、海深可用 deep 類型色階（視情境）。
  • 框線與刻度一致：frame=["af", "+tTitle"] 先固定風格，所有圖都用同一套。
  • 圖例與標註：研究圖的「可讀性」很多時候是圖例與標註決勝負。
  • 可重現：把 region、projection、cmap、字體參數集中在一段「設定區」。
進階：你可以把「出圖流程」包成函式，做成自己的小型繪圖框架（例如：地形底圖函式、事件疊點函式、圖例函式）。

你可能會遇到的坑

先知道先贏
  • 環境相依：建議 conda-forge 一套裝好。
  • 資料格式：GeoJSON 欄位/幾何不乾淨會噴 warning。
  • 投影與範圍：region 設太大或解析度太高，會慢到懷疑人生。
  • 透明度與層次：先鋪底圖，再疊線、最後疊點與文字。
✅ 心法：先把「底圖」做漂亮，再把「資料」疊得清楚。
